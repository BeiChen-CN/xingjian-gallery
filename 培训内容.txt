AI 小组培训安排（第九周至第十六周）


第一次：第九周

共同内容：
1. 简要介绍 AI、大模型、Agent 和 AIGC 的基本概念与常见用途。
2. 演示工具注册、安装或登录，以及如何清楚描述需求、查看结果并提出修改意见。
3. 介绍文件、文件夹和常用操作；编程组结合实际操作初步认识终端、Linux 与 Git，重点理解用途，不要求掌握复杂命令。
4. 介绍使用工具时的基本注意事项：检查生成结果，不随意公开账号密码、密钥和个人隐私。

Vibe Coding 组：认识网页由内容、样式和交互组成；在讲师指导下使用 AI 制作一个单文件网页，例如个人介绍页，并尝试修改文字和颜色。
AIGC 组：认识文字、图片、视频和声音生成工具；根据简单主题生成素材，尝试制作一段 15～30 秒的短视频。

课后作业：编程组完善个人介绍网页；AIGC 组完善短视频，并记录使用的工具和修改过程。
验收标准：学员能打开自己的作品，说明使用了什么工具，以及至少一次自己提出的修改。

第二次：第十周

Vibe Coding 组：
1. 讲解 HTML、CSS、JavaScript 的职责划分及前端基础架构。
2. 练习需求拆解、Prompt 编写与迭代，使用 AI 逐步生成和修改前端项目。
3. 结合项目练习保存文件和使用 Git 记录版本；简要认识 GitHub、Skills 和 MCP 的用途，重点放在基础操作。
4. 课堂实践：制作一个带简单交互的纯前端网页，例如待办事项清单或个人主页。

AIGC 组：
1. 学习故事梗概、简单剧本和分镜表的写法。
2. 练习使用提示词描述主体、场景、动作和画面风格。
3. 认识角色、场景等美术素材，尝试让同一角色在不同镜头中保持一致。
4. 课堂实践：围绕一个简单故事制作分镜表，并完成至少一个镜头素材。

课后作业：编程组完成网页并测试主要交互；AIGC 组按分镜制作一段约 1 分钟的完整短片。
验收标准：网页能打开且主要交互可操作；短片故事基本完整，并提交简要分镜表。

第三次：第十二周

Vibe Coding 组：
1. 讲解前后端架构、API 和数据持久化的基本原理与协作关系。
2. 介绍 GitHub 开源资源的检索与使用，理解项目文档、开源协议和素材使用条件。
3. 学习日志与报错分析、AI 辅助调试、功能测试，并用 Git 管理可运行版本。
4. 课堂实践：在已有网页基础上增加数据持久化功能，例如使用浏览器本地存储保存待办事项；有余力的学员可体验现成的后端服务或全栈示例。
5. 介绍多 Agent 协同的应用场景，作为进阶内容演示。

AIGC 组：
1. 学习角色人设、场景设定和世界观设计，控制项目范围。
2. 讲解剧本、分镜、美术资产生成与后期剪辑的 AIGC 工作流。
3. 练习 Prompt 迭代与素材筛选，改善角色和场景的一致性。
4. 课堂实践：为一个短片主题完成角色设定、故事梗概和部分分镜，生成或整理至少两个镜头素材。


课后作业：编程组完成带数据保存的网页，并记录一次发现和解决问题的过程；AIGC 组根据设定完成一段 1～2 分钟短片，整理剧本或分镜。
验收标准：网页刷新后仍能保留预期数据；短片能体现清晰的主题、基本连贯的镜头和角色设定。

第四次：第十四周

Vibe Coding 组：
1. 结合学员项目讲解基本项目结构、界面布局和常见技术选择。
2. 学习检查核心功能、处理常见错误、整理项目文件和编写简单使用说明。
3. 简要介绍持久化记忆及其适用场景
4. 课堂实践：开发一款Windows 或 Android 应用

AIGC 组：
1. 学习角色声音、背景音乐、字幕、镜头衔接和基础运镜。
2. 演示基础剪辑、音量调整和视频导出，练习根据反馈修改作品。
3. 介绍素材来源及音乐、图片、声音的使用权限；保存剧本、分镜和主要素材记录。
4. 课堂实践：确定最终短片，完成主要镜头制作和初步剪辑。

课后作业：编程组完善最终作品并准备项目文件和使用说明；AIGC 组完成约 2～3 分钟的最终短片，并整理剧本或分镜及素材来源。时间或基础有限的学员可完成更短但完整的作品；有余力者可增加时长或尝试更复杂的功能。
验收标准：编程作品主要功能可运行；视频具备完整的开头、过程和结尾，画面与声音基本协调。

第五次：第十六周

Vibe Coding 组：
1. 常见bug讲解
2. 工作流的搭建
3. 多模型协作

AIGC 组：
1. 学习高级剪辑，检查画面、声音、字幕和导出效果。
2. 长故事的编撰与视频架构的搭建
3.工作流的完善与agent的使用

课后作业：编程组需开发出可使用的软件 AIGC 组生成出可作为连续剧的视频
