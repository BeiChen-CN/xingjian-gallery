PART 01 · VIBE CODING

一个网页，由三部分组成

HTML

定义内容和结构：标题、输入框、按钮、列表。

CSS

决定视觉样式：颜色、字体、间距、布局。

JavaScript

实现交互行为：添加任务、删除任务、更新页面。

HTML 像房屋结构，CSS 像装修，JavaScript 让页面动起来。

VIBE CODING · 需求表达

先说清楚，再让 AI 动手

给谁用
目标用户做什么
主要功能长什么样
视觉风格怎么交付
文件和测试

先完成最小可运行版本，再通过对话逐步改进。

VIBE CODING · 提示词示例

示范：做一个待办清单

请制作一个供新生使用的单文件待办清单网页。包含输入框、添加按钮、任务列表和删除按钮；空内容不添加。采用蓝白配色，适配手机和电脑。请提供完整 HTML，并说明如何打开和测试。

提问：这里分别写清了哪些功能、样式和交付要求？

VIBE CODING · 现场练习

从一段需求，到一个网页

01新建项目文件夹和 index.html
02向 AI 提出需求，保存生成代码
03在浏览器打开网页，测试添加与删除
04测试空输入，检查是否符合预期
05修改标题或颜色，保存并刷新
06记录问题，继续向 AI 描述和追问
VIBE CODING · 迭代与排错

让 AI 帮你修改，需要说清什么？

描述问题

我做了什么？
我期望发生什么？
实际发生了什么？

提供上下文

相关代码或报错信息
运行环境与重现步骤
请 AI 解释原因并给出测试方法

“点击添加没有反应，请检查 JavaScript，说明原因并给出修改代码和测试步骤。”

VIBE CODING · 版本管理

为你的项目留下版本记录

git init
git add index.html
git commit -m "完成待办清单初版"

在已安装 Git 的前提下，于项目文件夹打开终端执行。首次提交可能需要配置用户名和邮箱。

认识几个工具

Git：记录版本
GitHub：托管与协作
Skills：为 AI 补充任务方法
MCP：连接工具和数据的协议

Skills 和 MCP 本次了解用途即可。

PART 02 · AIGC

把一个故事，拆成可以制作的镜头

故事梗概
发生了什么简单脚本
人物与情节分镜表
画面与声音素材与剪辑
生成并组合

示例：新生小林找不到教室，一位同学帮助他，两人一起到达教室。

AIGC · 分镜示例

一个故事，三个镜头

01 / 遇到问题

小林站在校园路口看地图。

远景 · 缓慢推进
“教室在哪里？”

02 / 得到帮助

一位同学指向教学楼。

中景 · 固定镜头
“跟我来！”

03 / 抵达教室

两人走进教室，相视一笑。

中景 · 平稳跟随
轻快音乐与字幕

画面、动作、景别、镜头运动和声音，都可以写进分镜。

AIGC · 画面提示词

写清画面，生成才有方向

主体场景动作风格景别与运镜

短发新生小林，穿蓝色连帽衫、背白色双肩包，站在阳光下的校园路口看地图，神情困惑。二维温暖动画风格，远景，镜头缓慢推进。

AIGC · 角色一致性

让观众认得出同一个角色

先建立角色设定

姓名：小林
发型：短发
服装：蓝色连帽衫
道具：白色双肩包

在每个镜头中复用

重复关键外观与风格；工具支持时使用角色参考图；逐张检查并修正变化。

不同生成工具提供的参考功能和效果有所不同。

AIGC · 现场练习

用一个镜头，开始制作

01用两三句话写出故事的开头、经过和结尾
02拆分至少三个镜头，写出画面与声音
03建立主角设定卡，明确外观与服装
04任选一个镜头，写出完整提示词
05用可用的工具生成至少一个镜头素材
06检查角色与分镜是否一致，记录修改点

使用素材前确认使用条件；提示词中不要输入密码、密钥或他人隐私。

AFTER CLASS · 课后作业

带走一个可以展示的作品

Vibe Coding

提交单文件网页，例如待办清单或个人介绍页。

验收：页面可以打开，主要功能可操作。

AIGC

按照分镜制作约 1 分钟动画短片，并提交主要分镜稿。

验收：故事基本连贯，画面可辨认。

课堂练习生成至少一个镜头素材；课后将镜头组织为短片。

CHECK & SHARE

展示之前，检查这三件事

01我的网页能打开，或视频能播放吗？
02主要功能可操作，或故事完整连贯吗？
03我能说明一次修改以及修改的原因吗？

交流作品：展示成果 · 分享过程 · 提出问题
